# شارع الحياة 🏙️

لعبة محاكاة حياة 3D بالعربي المصري: اشتغل في المكتبة، افتح محلات وسوبر ماركت، استورد من الصين، اشتري عربيات، وابني العاصمة الجديدة بلوك بلوك.

## العب
افتح صفحة اللعبة على GitHub Pages من الموبايل في كروم، وبعدين:
**التلات نقط ← تثبيت التطبيق (أو إضافة إلى الشاشة الرئيسية)**.
اللعبة بتشتغل شاشة كاملة ومن غير نت بعد أول فتحة.

## نقل التقدم من النسخة القديمة
في النسخة القديمة: الإعدادات ← «انسخ كود الحفظ».
في الأبلكيشن: الإعدادات ← «رجّع من كود» والصق الكود.

## ملف APK
حط لينك صفحة اللعبة في https://www.pwabuilder.com واختار Android عشان تطلّع APK (أو AAB لجوجل بلاي).

## الملفات
- `index.html` اللعبة كلها
- `three.min.js` مكتبة الـ3D (Three.js r128، رخصة MIT)
- `fonts/` خطوط Lalezar و Readex Pro (رخصة SIL OFL)
- `manifest.webmanifest` و `sw.js` عشان تبقى أبلكيشن وتشتغل أوفلاين

## التحديثات (للمطوّر)
اللعبة الأصلية ملف واحد (نسخة الآرتيفاكت). عشان تطلع نسخة أبلكيشن جديدة:
`python3 tools/build_app.py /path/to/index.html` وبعدين commit و push على `main`.
السكريبت بيعلّي رقم الكاش في `sw.js` عشان الأبلكيشن يتحدّث عند الناس.
