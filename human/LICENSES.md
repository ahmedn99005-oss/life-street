# ملفات الناس الحقيقيين / Real people assets

- **Body, clothes, hair, skins, eyes** (`body.glb.gz`, `shapes.bin.gz`, `proxies/`, `mobile/`, `manifest.json`):
  MakeHuman / MPFB community assets, **CC0-1.0**, packaged by the humanforge project
  (https://github.com/abdulrehman043/humanforge).
- **Runtime** (`hf.min.js`): humanforge runtime, MIT License, Copyright (c) 2026 humanforge contributors
  (full text below). Bundled with esbuild against the global three.js r128.
- **SkeletonUtils.js**: from three.js r128 `examples/js/utils`, MIT License, Copyright © 2010-2021 three.js authors.
- **Animations** (`anims.json`): idle / walk / run / agree / headShake clips extracted from the three.js
  example model `Xbot.glb` (Mixamo animations), used inside this game only.
